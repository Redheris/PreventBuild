The mod has been completely rewritten from a scratch.
Now it's more stable, more reliable, cooler, more understandable and easy to use.

### Changes and new features
- Configs are in YAML format now (`.yml`); 
- Using Identifiers (visible with `F3` and `F3 + H`) instead of translation keys;
- Support for vanilla # tags;
- Simple and pretty GUI for managing condition configs;
- Rewritten Wiki as well, including useful examples;
- Now available for 1.21.1, 1.21.4, 1.21.11 and 26.x
